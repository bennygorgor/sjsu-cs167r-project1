1 Population, theory, and prediction

Each observation is a count \(X\sim\operatorname{Binomial}(5,0.10)\), taking values 0 through 5. The 5 is the number of trials within one observation. The project sample size n is the number of independent such counts averaged in one Monte Carlo repetition; these are different quantities.

Here \(\mu=5(0.1)=0.5\) and \(\sigma^2=5(0.1)(0.9)=0.45\), so \(\sigma=\sqrt{0.45}\approx0.6708\) and \(\operatorname{SE}(\bar X)=\sqrt{0.45/n}\). The original population is right-skewed and highly discrete: \(P(X=0)=0.9^5=0.59049\).

The pre-simulation prediction is slower convergence than for the die because both asymmetry and visible probability jumps matter. Since \(n\bar X\sim\operatorname{Binomial}(5n,0.10)\), the theoretical skewness is \(0.8/\sqrt{0.45n}\) and excess kurtosis is \(0.46/(0.45n)\). The lattice spacing of the mean is \(1/n\); it never becomes a continuous distribution at finite n.

3 Experimental design and decision rule

Each experiment uses 30,000 independent samples, with n observations in each sample. Each sample contributes one mean. Thus, increasing n changes the sampling distribution; increasing the number of repetitions B improves the precision with which that distribution is estimated. The seed is reset to 5533 immediately before each experiment. Reusing a seed makes configurations reproducible, but results across different n are not claimed to be independent.

For each finite-variance population, the initial grid is 1, 2, 3, 5, 10, 20, 30, 50, 75, 100, 150, 200. After finding the first passing coarse value, the program fills in every integer from 1 through that value plus 4. It extends the integer search if needed. The Cauchy experiment instead uses 1, 2, 5, 10, 30, 100, 300, 1000, because finite-variance thresholds do not apply.

The working definition of “normal enough” was specified before running the simulations:

Numerical diagnostic Required value Purpose
Absolute moment skewness ≤ 0.30 Limit asymmetry
Absolute excess kurtosis ≤ 0.50 Limit differences in tail weight and peakedness
Maximum empirical CDF distance from the theoretical normal ≤ 0.05 Limit overall distributional discrepancy
Relative error in empirical standard error ≤ 0.05 Check agreement with the CLT scale

Skewness uses \(m_3/m_2^{3/2}\) and excess kurtosis uses \(m_4/m_2^2-3\), where \(m_k=B^{-1}\sum_{b=1}^B(\bar X_b-\overline{\bar X})^k\). These are moment estimates without small-sample bias correction. The reported kurtosis is excess kurtosis: a normal distribution has value 0, not 3.

For a population with finite mean and variance, set \(Z_b=(\bar X_b-\mu)/(\sigma/\sqrt n)\). The CDF diagnostic is \(D=\sup_z|\widehat F_B(z)-\Phi(z)|\), computed on both sides of every empirical jump. It uses the known population parameters, not a normal fitted to the simulated means. It is a descriptive error tolerance, not a p-value. No continuity correction is used for discrete populations, so this criterion deliberately counts discreteness as part of the approximation error.

The selected candidate is the smallest tested integer beginning five consecutive passing values (n through n+4). Histograms and full normal Q–Q plots are then inspected to assess whether the candidate is useful for the central shape and ordinary probabilities. Small tail departures are allowed; accurate extreme-tail probabilities are not promised. The five-value rule reduces dependence on one favorable estimate, but cannot remove Monte Carlo error or guarantee monotone improvement.

The tolerances are transparent working choices, not instructor-prescribed thresholds or universal constants. A stricter tail criterion could select larger n. No criterion based on a finite variance is applied to Cauchy data.

6 Conclusion and limitations

The selected value is n = 63. The empirical mean is 0.4997 versus 0.5, and empirical SE is 0.0846 versus the theoretical 0.0845. At n=62, the CDF discrepancy is 0.0513, compared with 0.0484 at the selected n.

The histogram becomes bell-shaped and the central Q–Q pattern approaches a straight line. Horizontal Q–Q steps persist. At n=30, skewness is 0.2243, already below 0.30, but CDF distance is 0.0704, above 0.05. Therefore n=30 fails the combined rule even though a skewness-only rule might accept it.

The noteworthy result is that this population needs a larger selected n than the exponential case under the chosen criteria. That does not establish an intrinsic ranking for every meaning of “normal enough”: here the uncorrected CDF criterion is sensitive to discrete jumps, whereas exponential convergence is chiefly limited by skewness. A continuity-corrected approximation to count probabilities could produce a different practical recommendation.

The candidate remains an empirical boundary, subject to seed and tolerance choices. It is not a claim that exact normality occurs at this n or that every later simulated diagnostic must improve monotonically.
